# Java Core Mastery: OOP & Logic Projects

This repository is a collection of 4 specialized Java console applications. Each project demonstrates core software engineering principles, ranging from Object-Oriented Programming (OOP) to complex data validation.

---

## 🚀 Projects Overview

### 1. [Task Management System](./Task-Management-System)
*Focus: Logic Validation & Time Tracking*
- Managed employee schedules within a specific 8.0 - 17.5 hour window.
- Implemented automated ID generation and strict date formatting (`dd-MM-yyyy`).
- **Key Tech:** `SimpleDateFormat`, `ArrayList`, `Exception Handling`.

### 2. [HR Candidate Management](./HR-Candidate-Management)
*Focus: Inheritance & Polymorphism*
- Designed a scalable system for Experience, Fresher, and Intern candidates.
- Used **Regular Expressions (Regex)** to validate Phone, Email, and Birth Dates.
- **Key Tech:** Inheritance, Polymorphism, Regex.

### 3. [Fruit Shop System](./Fruit-Shop-System)
*Focus: Data Structures & Collection Framework*
- Simulated a retail environment with inventory management and a customer shopping cart.
- Used `Hashtable` to track order history by customer name.
- **Key Tech:** `HashMap`/`Hashtable`, `List` manipulation.

### 4. [Number System Converter](./Number-System-Converter)
*Focus: Algorithms & Base Conversion*
- Created a utility to convert values between Binary (2), Decimal (10), and Hexadecimal (16).
- Built custom logic for string-to-number processing across different bases.
- **Key Tech:** Base conversion algorithms, String manipulation.

### 5. [SafeMove Backend](./SafeMove-Backend)
*Focus: Java Web API & Relational Modeling*
- Spring Boot backend mapped to SafeMove SQL Server schema (Account, Customer, Service, Survey, Contract, Payment...).
- REST APIs for master data, survey request creation, contracts and payments.
- **Key Tech:** Spring Boot, Spring Data JPA, SQL Server.

## 🛠 Skills Demonstrated
* **OOP Principles:** Encapsulation, Inheritance, and Polymorphism.
